# VLSI Design Portfolio

A collection of academic and independent projects covering Digital Logic Design, Analog and Mixed-Signal Circuit Design, Memory Architectures, and Custom CMOS Layout Development. This repository serves as a consolidated portfolio demonstrating design methodology, circuit implementation, simulation, verification, and physical layout skills developed throughout undergraduate coursework and self-driven learning.

---

## Portfolio Contents

### 1. Digital Systems and Logic Design

This portfolio showcases foundational digital design projects developed using RTL concepts, combinational logic, sequential logic, arithmetic circuits, and memory architectures.

#### Included Projects

* Integrated 8-Bit Computational System
* 11-Instruction ALU Design
* Custom 256-Bit SRAM Architecture
* Wallace Tree Multiplier
* Divider Architecture
* Warehouse Stock Management System

#### Key Skills Demonstrated

* Combinational Logic Design
* Sequential Logic Design
* Arithmetic Circuit Design
* Register Transfer Concepts
* Memory System Design
* Digital System Integration

### 2. Analog and Mixed-Signal Circuit Design

This portfolio contains transistor-level circuit designs and simulation studies developed using industry-standard analog design methodologies.

#### Included Projects

* Single-Stage CMOS Operational Amplifier
* Two-Stage CMOS Operational Amplifier
* Operational Transconductance Amplifier (OTA)
* Bandgap Reference Circuit

#### Key Skills Demonstrated

* CMOS Analog Design
* Gain and Bandwidth Analysis
* Frequency Compensation
* Stability Analysis
* Power Optimization
* Analog Simulation

### 3. Analog VLSI Layout Design

This portfolio presents custom CMOS layouts developed and verified through physical verification workflows.

#### Included Layouts

* 6T SRAM Cell Layout
* CMOS Schmitt Trigger Layout
* JK Flip-Flop Layout
* Operational Transconductance Amplifier Layout

#### Verification Performed

* Design Rule Check (DRC)
* Layout Versus Schematic (LVS)
* Parasitic Extraction
* Post-Layout Validation

#### Key Skills Demonstrated

* CMOS Layout Design
* Device Matching Techniques
* Analog Layout Practices
* Routing Optimization
* Physical Verification
